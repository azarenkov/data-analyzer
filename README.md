# Data Analyzer

Внутренний инструмент для анализа данных из файла: загрузка CSV/XLSX/XLS/JSON, просмотр структуры, базовая аналитика, фильтрация и сортировка, автоматические инсайты и экспорт результата.

## Запуск

### Docker (рекомендуемый способ)

Требуется Docker с Compose.

```bash
docker compose up -d --build
```

- Приложение: http://localhost:3000
- API (Swagger): http://localhost:8000/docs

### Локально без Docker

Backend (нужен [uv](https://docs.astral.sh/uv/)):

```bash
cd backend
uv sync
uv run uvicorn app.main:app --port 8000
```

Frontend (нужен Node.js 20+):

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется на http://localhost:5173 (dev-сервер проксирует `/api` на бэкенд).

Тесты бэкенда:

```bash
cd backend
uv run pytest
```

## Стек

- **Backend:** Python 3.13, FastAPI, pandas, openpyxl/xlrd/XlsxWriter, uv. Архитектура — DDD + Clean Architecture, четыре слоя:
  - `domain` — сущность `Dataset`, value objects (фильтры, сортировка, типы колонок), протоколы `DataTable` и `DatasetRepository`, доменные ошибки;
  - `application` — use cases (upload, overview, query, summary, top, group-by, time-series, insights, export, report) и порты (`DatasetParser`, `ReportBuilder`);
  - `infrastructure` — реализация таблицы на pandas, парсер файлов с собственной инференцией типов, генератор XLSX-отчёта, in-memory репозиторий;
  - `presentation` — роуты FastAPI, pydantic-схемы, маппинг доменных ошибок в HTTP.
- **Frontend:** React 19 + TypeScript, Vite, TanStack Query, Recharts. Структура — `api / components / hooks / lib / types / styles`.
- **Инфраструктура:** Docker Compose (backend — uvicorn, frontend — nginx со статикой и прокси `/api`).

## Что реализовано

- **Загрузка файла:** drag-and-drop или выбор файла; CSV (автоопределение разделителя и кодировки), XLSX/XLS, JSON. Несколько датасетов одновременно, переключение и удаление в сайдбаре.
- **Просмотр данных:** количество строк и колонок, тип и класс каждой колонки (число/категория/дата/текст/логический), количество пропусков и уникальных значений, предпросмотр первых строк.
- **Базовая аналитика:** summary statistics по числовым колонкам; топ/антитоп строк по выбранной метрике; группировка по категории с выбором агрегации (sum/mean/median/min/max/count) и bar-chart; динамика по времени с выбором даты, агрегации и шага (день/неделя/месяц/квартал) и area-chart.
- **Фильтрация и сортировка:** конструктор фильтров по любой колонке (=, ≠, >, ≥, <, ≤, содержит, из списка) с чипами, сортировка кликом по заголовку, пагинация, выбор колонки/метрики для анализа.
- **Инсайты:** автоматические наблюдения — тренды метрик между половинами периода, сильнейшие изменения по сегментам, корреляции, концентрация по категориям, качество данных (пропуски).
- **Экспорт:** отфильтрованный датасет в CSV или XLSX; полный отчёт XLSX (обзор, колонки, статистика, инсайты, данные).
- **Устойчивость:** аккуратная обработка краевых случаев — большие целые без потери точности, ведущие нули в кодах, литеральные `NA`-значения, смешанные типы в колонках, `inf`, таймзоны, лимиты Excel, лимит размера загрузки и защита от zip-bomb в XLSX; ~60 API- и юнит-тестов.

## Ограничения решения

- **Хранение в памяти:** датасеты живут в памяти процесса — рестарт бэкенда очищает всё; горизонтальное масштабирование невозможно без внешнего хранилища.
- **Один процесс:** аналитика выполняется в том же сервисе, что и API; очень тяжёлые операции на больших файлах будут занимать воркеры.
- **Нет авторизации:** инструмент рассчитан на доверенную внутреннюю сеть.
- **Лимиты:** загрузка до 50 МБ, XLSX-экспорт ограничен пределами Excel (1 048 575 строк, 16 384 колонки) — для больших выборок предлагается CSV.
- **Инсайты эвристические:** фиксированный набор правил (тренды, корреляции, концентрация), без статистической проверки значимости.
- **Отчёт только XLSX**, PDF не реализован.

## Что бы улучшил при наличии большего времени

- Персистентное хранилище (PostgreSQL/parquet на диске) вместо in-memory, чтобы датасеты переживали рестарт и работали на нескольких инстансах.
- Вынос тяжёлой аналитики в фоновые задачи (очередь) с прогрессом в UI.
- Сохранение «видов»: именованные наборы фильтров/сортировок/графиков, ссылки для шаринга с коллегами.
- Более богатые инсайты: аномалии, сезонность, сравнение периодов, статистическая значимость изменений.
- Кросс-фильтрация: применение фильтров вкладки «Данные» к аналитике и графикам.
- PDF-отчёт с графиками.
- E2E-тесты фронтенда (Playwright) и CI-пайплайн (lint, тесты, сборка образов).
- Виртуализация таблицы и потоковый парсинг для файлов существенно больше 50 МБ.
